### 【重要教训】查红线不能只搜全词
上一轮只 grep 了三个全词，结果**缩写变体漏网**：
- README 首屏就写着那个缩写（原词与形式**不在此写出**，见用户级记忆）
- 源码注释里 4 处同类缩写
- 记忆里 6 处 + 一个带 GitHub 用户名的项目名

而且**清理品牌词的提交信息和清理记录自己就写了品牌词**（在描述它），
被推上公开仓库才发现 —— 并且**第二次**又犯了（写本文件时又原样引用）。
**凡是写"清理了什么"的地方，一律不得写出原词与变体**，只说"某缩写/某词"。

**正确的三个搜索面**（缺一不可）：
```
grep -rliE "<词>|<缩写>" . --exclude-dir=.git --exclude-dir=node_modules   # 工作树
git log --all --pretty=format: --name-only | sort -u | grep -iE "<词>"      # 历史文件名
git log --all -p | grep -iE "<词>"                                          # 历史内容+提交信息
```
filter-repo 对应：`--path-rename` / `--replace-text` / `--replace-message`。
