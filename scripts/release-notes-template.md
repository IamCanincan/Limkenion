# Limkenion v{{version}}

简洁但够用的 DeepSeek 编程助手：命令行 + 浏览器界面，零运行时依赖。

## 安装

从本页附件安装（自包含，依赖已内联，可离线安装）：

```bash
npm install -g {{assetUrl}}
```

也可以解开 `limkenion-{{version}}.zip`，直接运行里面的 `limkenion.cmd`（Windows）或 `./limkenion`（macOS / Linux）。

首次使用填一次密钥即可，之后不用再设环境变量：

```bash
limkenion auth login              # 或在网页侧栏「接口密钥」里粘贴
```
